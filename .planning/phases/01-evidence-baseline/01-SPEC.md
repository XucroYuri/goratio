# 第一阶段 1A：证据基线与统计 CLI

状态：已冻结  
研究协议：`goratio-1a-v1`  
冻结日期：2026-09-02  
歧义度：`0.05`（门槛 `≤ 0.20`）

## 1. 产品边界

`goratio` 是金油比价历史统计与概率分析工具。它建立可审计的数据链、执行预注册的统计检验，并如实呈现支持、未支持或数据不足的结果。经济叙事只能形成待检验假设，不能替代统计证据。

本阶段不实现交易回测、择时信号、收益预测、原因归因、仓位计算、图表、告警、宏观因子、MCP、SKILL、动态插件加载或用户专业分层。输出不得给出方向性交易建议或收益保证。

## 2. 数据契约

### 2.1 来源与口径

| 来源 ID | 数据服务 | 黄金 | 原油 | 价格口径 | 币种 |
| --- | --- | --- | --- | --- | --- |
| `cn_public` | 新浪财经全球期货日线接口 | `GC`，COMEX 黄金连续期货 | `CL`，NYMEX WTI 原油连续期货 | 服务商拼接的连续合约日收盘价，不等同于交易所结算价 | USD/金衡盎司、USD/桶 |
| `yahoo_futures` | Yahoo Finance Chart API | `GC=F` | `CL=F` | 服务商连续近月期货日收盘价，不等同于交易所结算价 | USD/金衡盎司、USD/桶 |

默认来源为 `cn_public`。`yahoo_futures` 仅在用户明确选择后访问；遇到超时、限流或空响应时，错误必须说明海外网络、代理和稍后重试等排障方向。

两种来源都可能存在换月拼接跳跃、服务商历史修订、交易日历差异和非官方结算价偏差。程序必须显示来源名称、标的、价格口径、币种、最新共同交易日和实际跨度。

### 2.2 再分发与本地数据

仓库不打包任何没有明确再分发许可的价格历史。LBMA 历史基准数据尤其不得在未获许可时打包或再分发。用户可以：

1. 通过 `goratio update` 在本机生成缓存；
2. 导入自有标准 CSV；
3. 使用自己确认有权使用的数据快照。

标准 CSV 字段固定为 `date,gold_close,oil_close`，日期采用 ISO `YYYY-MM-DD`，价格必须是有限正数。缓存写入必须原子化，并保留来源元数据与获取时间。

### 2.3 校验与对齐

原始记录依次执行：

1. 校验字段完整性和 ISO 日期；未来日期与尚未完成的当日 K 线不进入分析；
2. 校验收盘价为有限正数；空值、非数、无穷值及非正数被剔除并计数；
3. 同一标的相同日期的完全相同重复项折叠为一条；冲突重复项的该日期全部剔除；
4. 按日期升序排序；
5. 以黄金和原油都存在的同一交易日作内连接，不做前向填充；
6. 对单日对数收益使用中位数绝对偏差诊断，稳健分数大于 `8` 仅标记为异常候选，不自动删除。

输出同时记录请求周期和实际共同样本周期。周期按最新共同交易日向前减去 `3/5/10` 个日历年；若起始日为闰日，则落到 2 月 28 日。

证据有效性的最低门槛固定为：共同跨度不少于 `1,825` 天且共同有效观测不少于 `1,000` 条。不足门槛时仍输出最新价格、比值与覆盖信息，但所有假设结论为“数据不足”。

### 2.4 降级顺序

固定顺序为：所选在线来源 → 该来源本地缓存 → 用户明确导入的标准 CSV。缓存超过 `72` 小时标记为陈旧，但只要内容可校验仍可用于价格与覆盖展示。不得静默切换到另一个来源，也不得把缓存结果标成在线结果。

## 3. 预注册研究协议

以下参数在查看研究结论之前固定。第一阶段不得根据结果追加窗口、阈值或过滤器；新模型必须使用新的研究协议版本。

### 3.1 试验清单

| ID | 假设 | 固定方法 | 通过条件 |
| --- | --- | --- | --- |
| H1 | 对数金油比存在均值回归证据 | 带截距、固定 1 阶差分滞后的 ADF 回归 | ADF t 统计量不高于 5% 临界值 `-2.86` |
| H2 | 关系存在结构变化 | 单均值断点 Sup-F 诊断；两侧各至少 `max(252, 20%样本)`；移动区块自助法 `500` 次、区块 `20`、种子 `20260902` | 自助 p 值 `< 0.05` 时标记不稳定风险；不产生方向结论 |
| H3a | 低分位状态后黄金 3 个月收益优于无条件基线 | 低状态为仅用当时及此前 5 年数据得到的经验分位 `≤ 20%`；63 个共同交易日远期收益 | 顺序样本外差值的 98.33% 家族置信区间下界大于 0 |
| H3b | 同上，6 个月 | 126 个共同交易日 | 同上 |
| H3c | 同上，12 个月 | 252 个共同交易日 | 同上 |
| H4 | 结论可跨时间和同口径来源复现 | 时间上采用前 `70%` / 后 `30%` 顺序切分；来源上分别运行两个来源的固定协议 | 方向、显著性和稳定性状态一致；缺任一来源则为数据不足 |

ADF 临界值是预注册的近似大样本阈值，不报告伪精确 p 值。结构诊断是 Bai–Perron 思路的简化单断点实验，不声称等价于完整 Bai–Perron 多断点检验。

### 3.2 滚动中枢与当前状态

CLI 接受 `3y`、`5y`、`10y` 展示周期。当前基线固定使用截至每个观测日的滚动 5 日历年：

- 中枢：比值中位数；
- 偏离度：`当前比值 / 滚动中位数 - 1`；
- 历史分位：滚动窗口中不高于当前值的观测占比；
- 全周期参考：所选实际样本的中位数与经验分位。

少于 `252` 个历史点时不计算当日滚动状态。所有滚动特征只使用当日及此前数据。

### 3.3 事件研究

每个 `3/6/12` 月期限均报告：

- 条件样本数与无条件样本数；
- 正收益比例；
- 算术均值、中位数、5% 和 95% 分位；
- 均值的 95% 移动区块自助置信区间；
- 条件均值减无条件均值及其 95% 区间；
- 用于三期限家族判断的 98.33% 区间；
- 样本内、样本外的起止日期和数量。

自助法固定 `1,000` 次、区块长度 `20`、种子 `20260902 + horizon`。重采样按时间连续区块进行。未来收益使用第 `t+horizon` 个共同交易日的黄金收盘价，不使用自然月近似，也不允许未来值参与状态分位。

前 70% / 后 30% 顺序切分还执行标签边界清除：事件日在切分点之前、但远期收益终点落在切分点或之后的记录不进入样本内集合，并单独记录清除数量。

单项结论枚举值仅为：

- `supported`：满足预注册通过条件；
- `not_supported`：数据充分但未满足；
- `insufficient_data`：历史、事件数或复制来源不足。

最低条件事件数固定为 `30`。负值、反向、置信区间跨零或结构不稳定均如实保留。

## 4. 公共接口

```text
goratio now --period 3y|5y|10y --source cn_public|yahoo_futures [--json]
goratio analyze --period 3y|5y|10y --source cn_public|yahoo_futures [--json]
goratio update --source cn_public|yahoo_futures [--import-csv PATH]
```

默认 `period=5y`、`source=cn_public`。在线请求必须有连接与总超时，不得无限等待。

结构化结果至少包含：

- `schema_version`、`as_of`、`protocol_version`；
- `source`、`price_basis`、`instruments`；
- `requested_period`、`actual_period`、`observation_count`；
- `data_quality`、剔除/异常计数、缓存状态与新鲜度；
- `ratio`、滚动中枢、偏离度、历史分位和全周期参考；
- `evidence_status`、条件远期收益、均值回归与稳定性诊断；
- `risk_flags`、方法局限和免责声明。

一期只定义静态 `PriceProvider` 抽象和两个内置实现，不实现动态发现、第三方插件加载或插件市场。

## 5. 验收矩阵

1. 在线验证 `cn_public` 的 GC/CL 共同日线不少于 5 年，并显示最新共同交易日和实际跨度。
2. 固定快照覆盖空值、重复、冲突重复、错位交易日、非正油价、异常值、短历史和陈旧缓存。
3. Yahoo 超时、限流和空数据均在有界时间内失败，并给出明确排障信息。
4. 固定快照验证比值、经验分位、偏离度、ADF、事件研究、断点诊断和 JSON 契约。
5. 时间切分测试证明训练数据未进入样本外区间；远期收益不前瞻泄漏。
6. 不足 5 年、结构不稳定和置信区间未支持时不产生方向性结论。
7. 扫描 CLI、README 和示例，不出现“建议买入”“建议卖出”“最优仓位”“保证收益”等承诺或指令。
8. 相同快照、协议版本和参数重复运行必须得到相同结果。

## 6. 报告与追溯

每份分析结果必须记录数据来源、快照 SHA-256、获取时间、协议版本、全部参数、试验数量、实际样本期、顺序切分点、未通过项目、缓存状态、限制与免责声明。结构变化只陈述统计不稳定性，不归因于战争、央行、供给冲击或其他事件。

## 7. 可证伪交付

第一阶段的成功标准是按冻结协议得到可复现结果，而不是证明金油比有效。样本外结果为零、反向或不稳定时同样构成合格交付；这些结果不得被删除、改写或通过事后调参掩盖。
